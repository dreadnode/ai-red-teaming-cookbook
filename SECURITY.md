# Security Policy

This repository contains **educational AI red teaming notebooks**. The attack
techniques here are intended for authorized security testing, research, and
learning against systems you own or are permitted to test.

## Reporting a vulnerability

If you find a security issue in this repository itself (for example a leaked
credential, a supply-chain risk in the CI, or a notebook that behaves unsafely),
please report it privately rather than opening a public issue:

- Use GitHub's **[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)**
  (the **Security** tab -> **Report a vulnerability**), or
- Contact the Dreadnode security team.

Please do not include real secrets or customer data in reports. We will
acknowledge receipt and work with you on a fix and disclosure timeline.

## Responsible use

These notebooks run attacks through the Dreadnode platform against targets you
provision. Only use them against models, endpoints, and agents you own or have
explicit authorization to test.
